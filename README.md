# Python 自主課題：クラスとオブジェクト

## 学習目標

`class`、`__init__`、`self`、属性、メソッドを使い、自分でクラスとインスタンスを作成します。最後に、2つのインスタンスがやり取りする処理を実装します。継承は使いません。

## ファイルと進め方

| 課題 | ファイル | 作成するインスタンス数 |
| --- | --- | --- |
| 1：学生 | `task1_student.py` | 2つ |
| 2：ゲームキャラクター | `task2_game_character.py` | 1つ |
| 3：銀行口座 | `task3_bank_account.py` | 2つ |

各ファイルにはクラスとメソッドの枠組みだけがあります。`# TODO` を読み、`pass` を自分の処理に置き換えてください。ファイルの最後にインスタンスの作成と動作確認のコードを書いてください。解答例は含まれていません。

Python 3を使用します。外部ライブラリは不要です。フォルダーをターミナルで開き、完成したファイルを実行します。

```sh
python task1_student.py
python task2_game_character.py
python task3_bank_account.py
```

環境によっては `python` の代わりに `python3` または `py` を使います。未実装の状態では、実行しても何も表示されません。

## 課題1：Student

学生を表す `Student` クラスを作成してください。

### 属性

| 属性名 | 内容 |
| --- | --- |
| `name` | 名前 |
| `age` | 年齢 |
| `department` | 学科 |
| `score` | 点数（0〜100の整数） |

`__init__(self, name, age, department, score)` で受け取った値を各インスタンスに保存します。この課題では、作成時に正しい範囲の値が渡されるものとします。

### メソッド

- `is_passed()`：点数が60点以上なら `True`、それ以外なら `False` を返します。
- `info()`：名前、年齢、学科、点数を表示します。表示形式は自由です。

### 動作確認

1. 名前や点数が異なる学生を2人作成してください。
2. 1人目を60点、2人目を59点に設定してください。
3. 両方の `info()` を呼び出してください。
4. 両方の `is_passed()` の戻り値を表示し、それぞれ `True`、`False` になることを確認してください。
5. 一方の学生の点数を変更し、もう一方の点数が変わらないことを確認してください。

## 課題2：GameCharacter

ゲームのキャラクターを表す `GameCharacter` クラスを作成してください。

### 属性

| 属性名 | 内容 |
| --- | --- |
| `name` | 名前 |
| `hp` | 体力（0〜100の整数） |
| `mp` | 魔力（0〜100の整数） |

`__init__(self, name, hp, mp)` で初期値を設定します。HP・MPが0未満なら0、100を超えるなら100に調整してください。数値には整数が渡されるものとします。

### メソッドとルール

- `take_damage(amount)`：指定した量だけHPを減らします。HPの下限は0です。MPは変えません。
- `heal(amount)`：指定した量のHP回復を試みます。実際に回復したHP 1につきMPを1消費します。
- 回復量は、指定量、HPが100になるまでの量、現在のMPの範囲内に収めてください。
- HPが100なら回復せず、MPも消費しません。MPが0なら回復できません。
- `amount` が0以下の場合は、日本語でメッセージを表示し、HP・MPを変更しません。
- ダメージによってHPが正の値から0になったとき、`Game Over` と表示してください。初期HPが0の場合も、作成時に表示してください。
- HPが0になった後は、回復もダメージ処理も行いません。日本語で行動できないことを表示してください。
- どのメソッドを実行した後も、HP・MPを0〜100に保ってください。

### 動作確認

キャラクターを **1体** 作成し、初期HPを80、MPを30にしてください。以下を順番に実行し、毎回HPとMPを表示します。

| 操作 | 期待するHP | 期待するMP |
| --- | ---: | ---: |
| 作成直後 | 80 | 30 |
| `heal(50)` | 100 | 10 |
| `heal(10)` | 100 | 10 |
| `take_damage(40)` | 60 | 10 |
| `heal(30)` | 70 | 0 |
| `heal(10)` | 70 | 0 |
| `take_damage(0)` | 70 | 0 |
| `heal(-10)` | 70 | 0 |
| `take_damage(200)` | 0 | 0 |
| `heal(20)` | 0 | 0 |

追加確認として、作成時のHP・MPを範囲外の値に書き換えて再実行し、0〜100に調整されることを確認してください。

## 課題3：BankAccount

銀行口座を表す `BankAccount` クラスを作成してください。

### 属性

| 属性名 | 内容 |
| --- | --- |
| `owner` | 口座名義人の名前 |
| `email` | アカウントのメールアドレス |
| `password` | 練習用パスワード |
| `balance` | 残高（円単位の整数） |

`__init__(self, owner, email, password, balance=0)` で値を保存します。初期残高には0以上の整数が渡されるものとします。メールアドレスやパスワードは架空の値を使ってください。この課題ではログイン処理は作成しません。パスワードを画面に表示しないでください。

### メソッド

- `check_balance()`：現在の残高を返します。呼び出す側で戻り値を表示してください。
- `deposit(amount)`：指定した金額を入金します。
- `withdraw(amount)`：指定した金額を出金します。
- `transfer(other_account, amount)`：この口座から別の口座へ送金します。相手の `BankAccount` インスタンスを引数として受け取ります。

呼び出し方の例：`account1.transfer(account2, 500)`

### 必須のチェック

- 金額には整数が渡されるものとします。入金・出金・送金で0以下の金額は受け付けません。
- 残高を超える出金・送金はできません。残高と同じ金額なら操作できます。
- 自分自身の口座には送金できません。送金先には `BankAccount` インスタンスが渡されるものとします。
- 操作できない場合は、日本語で理由を表示してください。どちらの口座の残高も変更しません。
- 送金が成功した場合は、送金元の残高を減らし、同じ金額だけ送金先の残高を増やしてください。

### 動作確認

口座を **2つ** 作成してください。初期残高は口座Aが1,000円、口座Bが500円です。以下を順番に実行し、毎回両方の残高を確認します。

| 操作 | 口座A | 口座B |
| --- | ---: | ---: |
| 作成直後 | 1,000円 | 500円 |
| Aに300円入金 | 1,300円 | 500円 |
| Aから200円出金 | 1,100円 | 500円 |
| AからBへ400円送金 | 700円 | 900円 |
| Aから800円出金しようとする | 700円 | 900円 |
| AからBへ800円送金しようとする | 700円 | 900円 |
| Aに0円入金しようとする | 700円 | 900円 |
| Aからマイナス100円出金しようとする | 700円 | 900円 |
| AからBへ0円送金しようとする | 700円 | 900円 |
| AからAへ100円送金しようとする | 700円 | 900円 |
| BからAへ900円送金 | 1,600円 | 0円 |
| Aから1,600円出金 | 0円 | 0円 |
